# Technical Support Management System

A web-based ticket management system developed using PHP and MySQL.

## Features
- User authentication system
- Ticket submission with category and priority
- Secure database queries using prepared statements
- MySQL database integration
- Basic ticket tracking

## Technologies Used
- PHP
- MySQL
- HTML / CSS
- Git & GitHub

## Installation
1. Import the SQL database
2. Configure config/db.php
3. Run using XAMPP
4. Access via localhost/technical-support-system
